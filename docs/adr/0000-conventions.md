# Repository Conventions

## Naming:

- kebab-case
- folders/packages, real names (`recipe-book`, not `project1`).
- descriptive names
- avoid lesson numbers

## Apps

Runnable self-contained projects/apps.

## Formatting

- TypeScript strict mode
- ESLint

## Runtime

**Runtime:** pnpm for installs (lockfile of record); `pnpm run <script>` or
`bun run <script>`
both work for execution.
