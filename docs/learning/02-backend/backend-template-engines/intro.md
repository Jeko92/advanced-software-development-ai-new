# Backend Template Engines - Intro

## Learning objectives

- Understand what template engines are and the problem they solve
- Set up Nunjucks with Express and configure your development environment for `.njk` files
- Share page structure across multiple views using template inheritance
- Render lists and conditional content with `for` loops and `if` statements
- Build reusable template components with macros

## Overview

In the last couple of years, frontend heavy frameworks like React and Angular have become increasingly popular. They offer a lot of value for building complex web apps, but they incorporate a lot of complexity. In many scenarios they are not the right tool for the job. Template engines are a great choice when your app does not need to have a rich dynamic UI. Then their small footprint and ease of use lets them shine. In this session, you will learn how to use Nunjucks to build a simple web app with Express.

Nunjucks is a powerful and widely used Node.js template engine developed by Mozilla. Its templating syntax follows widely used standards, meaning the core concepts carry over to other popular engines such as Jinja2 in Python or Twig in PHP. By the end, you will find out what those mysterious symbols such as `{{ }}` and `{% %}` mean and do.
