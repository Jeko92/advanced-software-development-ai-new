Backend SQL Advanced

This server reads and writes blog entries in a SQLite database, joined against authors and tags in related tables. Try the JSON API:

  • GET /api/blog-entries — all entries (INNER JOIN with authors)
  • GET /api/blog-entries/search?author=&search=&direction=&limit= — filtered, sorted, limited entries
  • GET /api/blog-entries/:id — a single entry, including its tags (many-to-many via blog_entry_tags)
  • POST /api/blog-entries — create an entry
  • PUT /api/blog-entries/:id — update an entry
  • DELETE /api/blog-entries/:id — remove an entry
  • GET /api/authors — all authors with their profile (one-to-one, LEFT JOIN so authors without a profile still appear)
